# Calm Ambient Music Tracks

Place your looped calm music MP3 files in this directory.

### Recommended File Names:
- `calm.mp3` (Default primary loop)
- `calm_1.mp3`, `calm_2.mp3`, etc. (For playlist / multi-track rotation)
- Or `calm_loop.mp3`

### Audio Specifications:
- **Format:** MP3 (stereo or mono)
- **Sample Rate:** 44.1 kHz or 48.0 kHz
- **Bitrate:** 128 kbps – 192 kbps (ideal for web loading)
- **Looping:** Seamless loop point (no abrupt click or tail silence)
- **Context:** Plays during Menu, Dock, Shipyard, Results, Level Editor, and calm sailing voyages.

# Intense Sailing Music Tracks

Place your looped intense sailing / battle / storm music MP3 files in this directory.

### Recommended File Names:
- `sailing.mp3` (Default primary loop)
- `sailing_1.mp3`, `sailing_2.mp3`, etc. (For playlist / multi-track rotation)
- Or `sailing_loop.mp3`, `storm.mp3`, `kraken.mp3`

### Audio Specifications:
- **Format:** MP3 (stereo or mono)
- **Sample Rate:** 44.1 kHz or 48.0 kHz
- **Bitrate:** 128 kbps – 192 kbps (ideal for web loading)
- **Looping:** Seamless loop point
- **Context:** Plays during intense sailing scenes, specifically levels featuring a **Kraken** or a **Storm** (e.g., Day 1 kraken encounter, Day 7 gale storm).
